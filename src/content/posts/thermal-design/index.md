# 电子设备热设计：从热阻模型到散热器选型

## 热是电子产品的第一杀手

Arrhenius 方程给出了温度与可靠性的定量关系：

$$\frac{AF}{10°C} \approx 2$$

即**芯片结温每升高 10°C，寿命大约减半**。在电源、功放和高性能 SoC 设计中，热设计不是锦上添花——它是可靠性的硬约束。

## 热阻模型：电路的欧姆定律

热学有一个优雅的类比——热阻模型：

| 电学 | 热学 |
|------|------|
| 电压 (V) | 温差 ΔT (°C) |
| 电流 (I) | 热流 P (W) |
| 电阻 (Ω) | 热阻 Rθ (°C/W) |

欧姆定律变成：$$\Delta T = P \times R_\theta$$

一个典型的从芯片到环境的热阻链：

```
Tj ──Rθjc──→ Tc ──Rθcs──→ Ts ──Rθsa──→ Ta
结温      壳温      散热器表面   环境温度
```

总热阻：$$R_{\theta ja} = R_{\theta jc} + R_{\theta cs} + R_{\theta sa}$$

## 实际计算：从功耗到散热方案

以一个实际场景为例：LDO 输入 12V，输出 5V，电流 1A：

$$P_{diss} = (V_{in} - V_{out}) \times I = 7V \times 1A = 7W$$

假设 LDO 的 $R_{\theta jc} = 5°C/W$，环境温度 $T_a = 25°C$，最大允许结温 $T_{j\_max} = 125°C$：

没有散热器时（$R_{\theta ja}$ 查手册 ≈ 50°C/W）：

$$T_j = 25 + 7 \times 50 = 375°C$$ ☠️ **严重过热！**

加上散热器（$R_{\theta sa} = 10°C/W$），用导热硅脂（$R_{\theta cs} ≈ 0.5°C/W$）：

$$T_j = 25 + 7 \times (5 + 0.5 + 10) = 133.5°C$$

仍然超了！这说明 LDO 不适合这种高压差大电流场景——应该换成 Buck DC-DC（效率 90%，功耗仅 0.5W）。

## PCB 热设计准则

### 铜箔就是散热器

PCB 上的铜箔不仅导电，也是最重要的导热路径之一。对于 1oz 铜：

- 热导率 ≈ 385 W/(m·K)（纯铜），但 PCB 上的铜很薄（35μm）
- 铜箔面积对热阻的粗略估算：10mm × 10mm 的 1oz 铜皮，热阻约 25°C/W

**散热焊盘（Thermal Pad）**：QFN/DFN 封装底部的散热焊盘必须：
1. 直接接到大面积地铜
2. 添加足够多的散热过孔（φ0.3mm, ≥ 9 个）
3. 过孔连接到内层和底层地平面

### 过孔的散热阵列

```
┌──────────────────────────┐
│ ● ● ● ● ● ● ● ● ● ● ●  │  ← 顶部铜皮
│ ● ● ● ● ● ● ● ● ● ● ●  │
│ ● ● ● ● ● ● ● ● ● ● ●  │  ← 散热过孔阵列（φ0.3mm, pitch 1mm）
│ ● ● ● ● ● ● ● ● ● ● ●  │
└──────────────────────────┘
         ↓  ↓  ↓
    ─────────────────  内层 GND 平面
         ↓  ↓  ↓
    ─────────────────  底层铜皮
```

每个过孔的热阻约 50-100°C/W，9 个并联 → 约 5-10°C/W。

## 散热器选型步骤

1. 确定最大允许热阻：$R_{\theta sa(max)} = (T_{j\_max} - T_a) / P_d - R_{\theta jc} - R_{\theta cs}$
2. 查看散热器规格书中的 Rθ vs. 风量曲线
3. 自然对流条件下，选择 $R_{\theta sa}$ 比计算值低 20% 的散热器（预留余量）
4. 验证：红外热像仪实测结温

### 风冷对散热器性能的影响

| 风量 (LFM) | Rθ 改善（相对自然对流） |
|------------|----------------------|
| 0（自然对流） | 基准 |
| 100 | -40% |
| 200 | -55% |
| 400 | -70% |

## 热仿真工具

对于复杂系统，手动计算无法准确预测热分布。三个主流工具：

- **FloTHERM**：电子散热领域最成熟，元器件库丰富
- **Icepak**（ANSYS）：与 ANSYS 生态集成好
- **OpenFOAM**：开源 CFD，学习曲线陡但免费

> 热设计的核心原则：**尽早做、多留余量**。到了量产阶段发现芯片过热，改板周期和成本都会让你后悔没有在设计初期用好一个热阻计算器。
