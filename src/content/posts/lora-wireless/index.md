# LoRa 无线通信实战

## LoRa 为什么能传那么远

传统 FSK 调制的接收灵敏度约为 -110dBm 左右。LoRa 通过 CSS（Chirp Spread Spectrum）扩频调制，在相同条件下可以达到 -137dBm 甚至 -148dBm。

这不是魔术，而是物理和数学的必然：**带宽换信噪比**。

## CSS 调制原理

LoRa 的核心是 chirp 信号——频率随时间线性变化的信号：

$$s(t) = A \cdot e^{j2\pi(f_0 t + \frac{k}{2}t^2)}, \quad k = \frac{BW}{T_{sym}}$$

其中关键参数是**扩频因子 SF**：

| SF | 符号周期（BW=125kHz） | 符号比特数 | SNR 增益 |
|----|----------------------|-----------|---------|
| SF7 | 1.024 ms | 7 bits | 基准 |
| SF9 | 4.096 ms | 9 bits | +5 dB |
| SF12 | 32.768 ms | 12 bits | +10 dB |

高 SF 意味着更远的距离，但以更低的速率和更高的功耗为代价。

## 链路预算

Friis 传输方程：

$$P_{RX} = P_{TX} + G_{TX} + G_{RX} - L_{path}$$

$$L_{path} = 20\log_{10}(d) + 20\log_{10}(f) + 32.45$$

以 SX1276 为例进行实际链路预算：

| 参数 | 值 |
|------|-----|
| 发射功率（允许最大） | +20 dBm |
| 发射天线增益 | 2 dBi |
| 接收天线增益 | 2 dBi |
| 接收灵敏度 SF12/BW125kHz | -137 dBm |
| **最大允许路径损耗** | **161 dB** |
| **对应自由空间距离（868MHz）** | **约 15km** |

实际城市环境因障碍物会比自由空间少 20-40dB。

## LoRaWAN vs 私有协议

| 维度 | LoRaWAN | 私有 LoRa |
|------|---------|----------|
| 组网复杂度 | 需要网关+网络服务器 | 点对点，零基础设施 |
| 标准化 | 标准协议，多厂商互操作 | 自定义协议 |
| 功耗 | A 类设备极低 | 取决于自行设计 |
| 适用场景 | 智慧城市、农业 | 机器人遥控、私有传感器网 |

## 天线系统设计

天线是射频链路中最容易被忽视的一环。几个关键提示：

- **接地平面至关重要**：λ/4 单极天线至少需要 λ/4 × λ/4 的地平面
- **SWR（驻波比）< 2:1** 是基本要求，< 1.5:1 是良好水平
- **馈线损耗**：RG316 在 868MHz 时损耗约 1.5dB/m——放在天线端比放在板子端重要得多

## 实际部署经验

实测数据（城市环境，SF12，BW=125kHz，+14dBm）：

```
距离    RSSI      SNR   丢包率
500m   -98dBm   +2dB    0%
1km    -108dBm  -5dB    2%
2km    -118dBm  -12dB  15%
3.5km  -125dBm  -17dB  40%   ← 接近极限
```

> LoRa 不是万能药。它擅长少量数据、低功耗、远距离的场景。如果你需要实时视频流，去看 Wi-Fi 或 5G；如果你需要覆盖整个城市的低速率传感器网，LoRa 是当下最好的选择之一。
